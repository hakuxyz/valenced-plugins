# Current Plugins

## Fake Profile Themes

Profile theming with colors hidden in your bio using invisible 3y3 text. A port of ryan's FakeProfileThemes for Vendetta, compatible with bios from Vencord, Vendetta and Revenge.

- **Color picker in the profile editor**
  Open your profile editor and pick a primary and accent color with Discord's own color picker. No hex codes needed.
- **Copy 3y3**
  Copy the hidden text and paste it anywhere in your bio.
- **Live preview on your profile**
  Your own profile shows the selected colors right away.
- **Nitro friendly**
  Optional setting to keep your real Nitro colors if a profile has both.
