# Current Plugins

## Fake Profile Themes
Profile theming with colors hidden in your bio using invisible 3y3 text. A port of ryan's FakeProfileThemes for Vendetta, compatible with bios from Vencord, Vendetta and Revenge.

- **Color picker in the profile editor**
-# Open your profile editor and pick a primary and accent color with Discord's own color picker. No hex codes needed.
- **Copy 3y3**
-# Copy the hidden text and paste it anywhere in your bio.
- **Live preview on your profile**
-# Your own profile shows the selected colors right away.
- **Nitro friendly**
-# Optional setting to keep your real Nitro colors if a profile has both.

-# **Note:** The color picker can sometimes fail to open in the plugin settings. If that happens, open your profile editor once - the picker loads with it - then try again in the plugin settings. This usually only needs to be done once per app launch.

The plugin is CC0. The original authors are credited in the manifest, LICENSE and NOTICE files.

## Server Notes
Add notes and custom color tags to servers to keep track of them.

- **Notes per server** - add, edit, or remove a note for any server
- **Color tags** - choose from preset colors or pick any custom color
- **Easy to access** - manage notes from plugin settings and, when available, from the server menu
- **Local storage** - notes and tags are stored locally on this device

The plugin is CC0.
